# FUTURE_fS_02# 🚀 Mini CRM - Lead Management System

A simple Full Stack CRM app to manage client leads.

Built as part of **Future Interns Task 2 (2026)**.

---

## 🔥 Features
- Add leads (name, email)
- View leads in table
- Update status (New / Contacted / Converted)
- Add notes
- Delete leads
- Simple admin login

---

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Node.js, Express.js
- MongoDB
